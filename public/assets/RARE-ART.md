# Rare catalog artwork

`rare-lots-v1.png` is the eight-cell concept illustration generated for Second Value with the built-in imagegen tool and accepted for game integration. It contains a 4-column, 2-row sheet in this order:

1. Midnight Regulator
2. Tidewatch Wireless
3. Blue Line Service Cup
4. Unsailed Voyage Medal
5. Last Service Camera
6. Night Pilot Chart
7. Coronation Prop Clock
8. Silver Ink Stage Chart

Style brief: isolated worn antique objects on dark forest green, painterly museum detail, warm amber light, brass, walnut, porcelain and aged paper; no captions or watermark. The full design prompt is retained in the local design deliverable `outputs/rare-catalog-design/ART-PROMPT.txt`.

Revealed images are selected only after an object's identity is known. Unknown cards always use the existing generic outline sheet.
