# Catalog 19–24: second artwork revision

These six standalone painterly images replace the simple vector sheet in revealed game cards, item details, sale screens and the Discovery book. Unknown objects still use the original generic covered artwork.

- Railway cabinet clock — `railway-cabinet-clock-v2.png`
- Cracked porcelain cup — `cracked-porcelain-cup-v2.png`
- Naval service badge — `naval-service-badge-v2.png`
- Replica folding camera — `replica-folding-camera-v2.png`
- Console receiver — `console-receiver-v2.png`
- Original railway map — `original-railway-map-v2.png`

All six were created with the built-in imagegen tool. The prompts are retained beside them in `clock-cup-map-prompts.md` and `badge-camera-radio-prompts.md`. The shared direction is realistic antique materials, a dark forest-green background, warm upper-left light, a complete centered object and consistent surrounding space.

The PNG files are the original generated images. The game loads corresponding lossless WebP delivery copies with identical decoded pixels, avoiding an unnecessary PNG download. No cropping, resizing or repainting is applied during encoding.

The cabinet clock is a tall floor-standing piece, the folding camera has visible extended bellows and support rails, and the console receiver is furniture-sized. Game identities, ordinary prices, probabilities and abilities are unchanged by this artwork revision.
